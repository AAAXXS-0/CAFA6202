# 统一 50% 黑白划线实验

本目录只验证分表后的物理行列边界，不接正式流水线、切块或模型。

```mermaid
flowchart TD
    A001["001 V2 上下分表"] --> A002["002 子表统一生成原图 50% 分析图"]
    A002 --> A003["003 墨迹晕染，定位主要表格块"]
    A003 --> A004["004 在主体块中按原规则找黑线"]
    A004 --> A005["005 擦除通过单线规则的黑线线芯"]
    A005 --> A006["006A 文字只向左右夸张扩张，寻找行白缝"]
    A005 --> A007["006B 文字只向上下夸张扩张，寻找列白缝"]
    A006 --> A008["007 黑线作为硬边界，白线补缺；近线合并且黑线优先"]
    A007 --> A008
    A008 --> A009["008 得到最终横向与纵向边界"]
    A009 --> A010["009 映射回原图，形成固定 R×C"]
    A010 --> A011["010 保存全部中间图和诊断 JSON"]
```

关键约束：

- 分表固定使用 `tests/图表分表实验/002_横向分表V2.py`；
- 表头打断白缝时，从上方白缝落刀，让表头归入下表；
- 50% 图只用于分析，实际识别图片仍保持原图原尺寸；
- 找行白缝时只左右扩张，找列白缝时只上下扩张；
- 当前扩张比例先统一测试 1%，后续按中间产物调整；
- 黑线规则暂时沿用正式代码，不在本实验中调参。
