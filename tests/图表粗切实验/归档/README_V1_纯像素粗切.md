# 图表粗切实验

本实验不修改正式流程，只验证下面这条路线：

    现有横向分表
    → 约3200像素责任区粗切，四周保留256像素重叠
    → 官方API输出二维矩阵
    → 行列内容序列对齐
    → 差行补空行、差列补空列

中间产物全部使用中文名称，位于：

    work/验证/粗切块相信模型V1/

先只生成切块：

    /home/zero/miniconda3/envs/AFAC2026/bin/python       tests/图表粗切实验/001_粗切块与模型拼接.py --仅预处理

只跑一张样本并调用API：

    /home/zero/miniconda3/envs/AFAC2026/bin/python       tests/图表粗切实验/001_粗切块与模型拼接.py --只跑 185a2337

API成功响应会立即写入独立SQLite缓存。只有响应能够解析成HTML或Markdown
表格时才记为成功缓存。


## 已实现的失败处理

- 标准HTML或Markdown表格直接解析成模型二维矩阵。
- 连续至少3行、列数稳定的空格分隔纯文字，也可恢复成矩阵。
- 官方后台提示词回显视为空白尾块，不制造假表格。
- HTML截断时保留父块、坏响应和实际图片，沿长边自动二分。
- 子块仍截断时最多递归3层；修复后的父矩阵重新写入SQLite缓存。
- 所有自动复切图片、原始响应、子矩阵和拼接审计均实际落盘。

## 当前结论

参见同目录的《实验结论.md》。目前路线已证明可行，但固定尾部/头部重叠列
仍不足以处理模型OCR错列；正式替换前需要升级成列序列动态对齐。
